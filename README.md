# Claude Skills for everyday AI work

15 small Claude Skills (plain `SKILL.md` instruction files) for checking, handing off and reporting AI work. Each one is a short set of instructions your AI agent follows. 每個都是一份給 AI 看的短說明檔（SKILL.md）。

**Agensi = text version. Gumroad = full version.** Agensi 上架的是文字版本；Gumroad 上架的是完整版本。

Not tested on every AI tool. 並非所有 AI 工具都測過；主要在 Claude 上使用。

### 補助導航：五分鐘試用（免費）

1. 用 Claude Code 並開啟網路查詢。依 [補助導航安裝說明](https://github.com/water9010-source/welfare-guide#安裝) 安裝，重開 Claude Code。
2. 貼上這個假案例：「請用補助導航。家人 72 歲，住新北市板橋區，中風後洗澡需要人幫忙，目前人在家、沒有緊急危險。想知道長照要從哪裡申請、要準備什麼。」
3. 預期會看到：先打 1966，附新北市長照申請入口及申請書、同意書，說明後續到府評估。若還缺資料，AI 會先問，不需要輸入身分證字號。結果是申請方向，不保證核准。

3. **Plain Report** - if AI replies are hard to read.
