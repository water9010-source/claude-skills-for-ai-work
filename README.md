# Claude Skills for everyday AI work

Nine small Claude Skills (plain `SKILL.md` instruction files) for checking, handing off and reporting AI work. Each one is a short set of instructions your AI agent follows. 每個都是一份給 AI 看的短說明檔（SKILL.md）。

Not tested on every AI tool. 並非所有 AI 工具都測過；主要在 Claude 上使用。

## List 清單

|---|---|---|
| Session Handoff ($1) 對話接續交接 | Long chat getting expensive? Write a short handoff file and continue in a new window | [Gumroad](https://aquaquest23.gumroad.com/l/ncrbbh) |
| Done Criteria ($1) 工作完成標準產生器 | Turn a one-line request into checkable done-criteria, confirm, then start | [Gumroad](https://aquaquest23.gumroad.com/l/ojzbzb) |
| Plain Report ($1) 給 AI 的白話回報規則 | Result first, plain words, done / not done / your decision kept apart | [Gumroad](https://aquaquest23.gumroad.com/l/zmrhxq) |
| Clear Brief ($1) 交辦單寫法 | Four rules for handing work to another AI without being misread | [Gumroad](https://aquaquest23.gumroad.com/l/eucgh) |

## Where to start 從哪裡開始

1. **Session Handoff** - if your chats get long and token costs climb.
2. **Done Criteria** - agree on "done" before the AI starts.
3. **Plain Report** - if AI replies are hard to read.
