# Claude Skills for everyday AI work

Ten small Claude Skills (plain `SKILL.md` instruction files) for checking, handing off and reporting AI work. Each one is a short set of instructions your AI agent follows. 每個都是一份給 AI 看的短說明檔（SKILL.md）。

Not tested on every AI tool. 並非所有 AI 工具都測過；主要在 Claude 上使用。

## Where to start 從哪裡開始

1. **Session Handoff** - if your chats get long and token costs climb.
2. **Done Criteria** - agree on "done" before the AI starts.
3. **Plain Report** - if AI replies are hard to read.
